# Facebook Invite Auto Scroll
Android 14+ Kotlin AccessibilityService project matching the supplied floating-control concept.

Features:
- Exact "Invite" matching, so "Invited" and "Following" are not treated as Invite.
- Automatic visible scrolling when no eligible Invite is found.
- Configurable maximum and delay.
- Floating Start/Stop controls.
- GitHub Actions APK build.

This project intentionally does not include stealth, randomized human imitation, anti-detection, or platform-control bypass logic.

Build: open in Android Studio, sync Gradle, then build the debug APK. GitHub Actions also builds app-debug.apk on pushes to main or manual workflow runs.
